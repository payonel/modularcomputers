A broken computer: cracked glass, missing keys, an empty board. It is left behind by whoever built
computers here before you.

## Use

It is decoration. Nothing works, and nothing opens. It faces you when you place it. Break it and it
is gone: it drops nothing.

## Notes

- You are meant to find these in the world, in the ancient sites.
- For a computer that works, see the [case](/hardware/case/).
