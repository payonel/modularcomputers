These tutorials take you from an empty crafting table to computers that talk to each other. Do them
in order: each one uses what the one before it built. Every tutorial starts with a checklist of what
you need, tells you what you will see after each step, and says what it means when something goes
wrong.

1. [Your first computer](/tutorials/first-computer/). For everyone. Assemble a [case](/hardware/case/)
   with a [CPU](/hardware/cpu/), [RAM](/hardware/memory/), an [EEPROM](/hardware/eeprom/), a
   [disk](/hardware/disk/) and a [screen](/hardware/screen/), power it, and boot [mcos](/mcos/boot/).
2. [Your first program](/tutorials/first-program/). For anyone who has never used a Linux shell.
   Write a Lua program with the [editor](/programs/edit/), run it with [lua](/programs/lua/), and
   learn the shell session around it.
3. [Redstone](/tutorials/redstone/). For builders. Put a [redstone card](/devices/redstone-card/) in
   your computer, read a lever, light a lamp, and name the sides with [faces](/concepts/faces/).
4. [Two computers](/tutorials/two-computers/). For anyone who wants machines to cooperate. Join two
   computers with [network cards](/devices/network-card/) and a [cable](/hardware/cable/), then run
   commands and copy files between them with [rsh](/programs/rsh/) and [rcp](/programs/rcp/).
5. [The Disk Station](/tutorials/disk-station/). For anyone with more than one disk. Format, clone
   and install mcos onto disks with the [Disk Station](/hardware/disk-station/).
6. [Your own service](/tutorials/service/). For anyone with a program that should keep running.
   Make it a service that runs in the background and starts at boot, with [rc](/programs/rc/).
7. [Coming from OpenComputers](/tutorials/from-opencomputers/). For OpenComputers players. What you
   did with components, signals, the GPU and robots, done the mcos way.

If you want to know why something works the way it does, the [concepts](/concepts/) pages explain
the ideas ([the bus](/concepts/bus/), [power](/concepts/power/), [names](/concepts/names/)), and the
[mcos](/mcos/) pages explain the operating system.
